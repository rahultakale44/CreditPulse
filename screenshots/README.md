# Dashboard Screenshots

Add your Power BI dashboard screenshots here with the following names:

## Required Screenshots

1. **executive-overview.png** - Executive Overview Dashboard
   - Shows total revenue, customers, transaction volume KPIs
   - Revenue trends and card category distribution

2. **customer-demographics.png** - Customer Demographics Dashboard
   - Age distribution, gender split
   - Income and education level analysis
   - Geographic distribution

3. **transaction-analysis.png** - Transaction Analysis Dashboard
   - Transaction trends over time
   - Payment method distribution
   - Expense category breakdown

4. **credit-performance.png** - Credit Performance Dashboard
   - Credit utilization analysis
   - Delinquency tracking
   - Activation rates

5. **geographic-analysis.png** - Geographic Analysis Dashboard
   - State-wise customer distribution
   - Revenue by region
   - Top zipcodes

## How to Add Screenshots

1. Take screenshots of your Power BI dashboards
2. Save them with the exact names listed above
3. Place them in this directory (screenshots/)
4. The README.md will automatically display them

## Tips for Quality Screenshots

- Use high resolution (at least 1920x1080)
- Capture full dashboard view
- Ensure all visuals are properly loaded
- Use consistent filters across screenshots
- Remove any sensitive/real customer data
